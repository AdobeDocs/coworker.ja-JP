# 共同作業プロジェクトについて {#overview}

>[!AVAILABILITY]
>
>共同作業プロジェクトの空き状況は限られています。 詳細については、Adobe アカウント担当者にお問い合わせください。

Coworker Projectsは、実務担当者が再利用可能なワークフローを使用して、エンドツーエンドの顧客体験作業を完了させる共有体験です。 ワークフローは、Adobe CX Enterpriseとサードパーティアプリケーション全体で、人、担当者、スキル、ビジネスコンテキストを結びつける役割を果たします。 ガバナンスと人間の意思決定が、作業の最初から最後までをガイドします。

許可されたユーザーは、プロジェクトテンプレートを作成、公開、管理できます。 実務担当者は、テンプレートを使用してビジネス施策のプロジェクトを開始し、チームと協力して、承認ゲートで意思決定をおこないます。

>[!NOTE]
>
>共同作業者プロジェクトと[共同作業者チャット &#x200B;](/help/chat/overview.md)は、Adobe CX Enterprise Coworkerのモジュールです。 このページでは、共同作業プロジェクトについて説明します。

## 含まれるプロジェクトテンプレート {#project-templates}

一般的なマーケティングのユースケースに対応する付属テンプレートから始めましょう。 各テンプレートには、ビジネス要件に適応するための、繰り返し可能なワークフローが用意されています。 次の5つのテンプレートから選択して、Coworker Projectsでプロジェクトを開始します。

### 統合オーディエンスとオーケストレーションされたジャーニー {#unified-audiences-orchestrated-journeys}

カスタマージャーニー全体でB2C キャンペーンを計画、立ち上げ、測定します。 Adobe Real-Time CDPを使用してオーディエンスを構築し、アクティベートし、Adobe Journey Optimizerを使用してローンチからキャンペーンを連携します。 Adobe Customer Journey Analyticsでパフォーマンスを把握。

決定、検証、承認、測定のために、繰り返し可能なプロセスに従う。 組織のブランド、同意、法律、ガバナンスの要件を適用します。

必要な互換性のあるアプリケーション：Adobe WorkfrontとMarketo Engage。

### キャンペーンの立ち上げに必要な企業概要 {#enterprise-brief-campaign-launch}

B2B キャンペーンの概要を、すぐに実行できるメールキャンペーンに変換。 Workfrontで計画と共同作業を管理し、[!DNL Adobe Marketo Engage]でキャンペーンを構築して準備します。

送信前に品質チェックと必要な承認を完了し、Workfrontで結果を取得します。 計画から実行、測定に至るまで、反復可能なプロセスに従う。

必要な互換性のあるアプリケーション：Adobe Journey Optimizer （B2C）、Real-Time CDP、および[!DNL Adobe Customer Journey Analytics]。

### 有料メディアキャンペーン {#paid-media-campaign}

調整されたワークフローを通じて、有料メディアキャンペーンを計画、開始、最適化します。 Workfrontを利用して、目標、予算、タイミング、目標、意図する成果を達成する。 Real-Time CDP、[!DNL Adobe GenStudio for Performance Marketing]、および[!DNL Adobe Experience Manager Assets]をまたいで、オーディエンス、クリエイティブ、およびターゲティングを調整します。

公開前に検証を完了し、経費の承認を行います。 続いて、最適化の推奨事項を確認し、キャンペーンを終了します。

必要な互換性のあるアプリケーション：[!DNL Adobe GenStudio for Performance Marketing]、Real-Time CDP、[!DNL Adobe Experience Manager Assets]、Workfront

### キャンペーンとジャーニーのヘルスウォッチ {#campaign-journey-health-watch}

Journey Optimizerでキャンペーンとジャーニーの運用状態をモニターします。 設定されたモニタリングウィンドウで、ライブジャーニーと関連オーディエンスを確認できます。 公開、停止、配信に失敗したイベントを含むキャンペーンを特定し、可能性の高い原因と推奨される次のステップを確認できます。

レビュー全体で、新規、未解決、解決済みなどの結果を追跡できます。 Journey Optimizerに変更を加えずに問題を監視します。

対応アプリケーション：Journey Optimizer

### 実験パフォーマンスのレビュー {#experiment-performance-review}

実験のパフォーマンスを確認し、実行すべきアクションを決定します。 Adobe Journey Optimizerと[!DNL Adobe Customer Journey Analytics]のテスト機能を使用して、アクティブなテストを一貫して評価します。

定期的なレビューで結果と意思決定を把握。 成功している顧客体験を前進させる準備ができているか、または期待する成果を達成できていない顧客体験を特定するために、行動が必要です。

必要な互換性のあるアプリケーション：Journey OptimizerとCustomer Journey Analytics。

## プロジェクト体験 {#project-experience}

同僚プロジェクトを使用して、ビジネス目標に沿ってワークフローを調整します。

* 目標の&#x200B;**ワークフロー：** ガバナンスと人間の承認ゲートを使用して、複数のエージェントを調整するワークフローを設計およびデプロイします。
* **アダプティブ実行：**&#x200B;トリガーは、イベント、シグナル、またはスケジュールを通じて作業します。 目標に対する成果を評価し、その結果にもとづいて対応を調整またはトリガーします。
* **Collaborationと承認：**&#x200B;共有プロジェクト内で、ワークフロー全体を通じて関係者が利用できるコンテキストを使用して、レビュー、承認、およびアクションを実行します。
