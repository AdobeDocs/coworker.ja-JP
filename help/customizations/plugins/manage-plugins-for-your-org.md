# プラグインとマーケットプレイスを管理

管理者が、既存のAdobeの権限との整合性を維持しながら、承認済みプラグインでAdobe Workfront Chatを拡張し、マーケットプレイスを管理して、スキルや接続されたツールへのアクセスを管理する方法をご紹介します。

>[!VIDEO](https://video.tv.adobe.com/v/3504183/?captions=jpn&learn=on&enablevpops)

## 学習すること
 
このビデオでは、Adobe Workfrontでのプラグイン管理の仕組みと、管理者がチームに新しい機能を安全に導入する方法について説明します。
 
主な内容：
 
- マーケットプレイス、プラグイン、スキル、MCP サーバーの違い
- Coworkerで使用するプラグインでスキルと接続サービスをパッケージ化する方法
- Adobeの製品権限と製品プロファイルが機能へのアクセスを決定する理由
- Coworkerが接続されたAdobe製品から権限を自動的に継承する方法
- Experience Cloud組織とExperience Platform サンドボックスの検証が重要な管理手順である理由
- Coworkerのカスタマイズ領域のナビゲーション方法
- GitHub リポジトリを使用して新しいマーケットプレイスを追加する方法
- 組織のプラグインのインストールと管理方法
- プラグインに含まれるスキルをデプロイ前に確認する方法
- ユーザー自身がプラグインをインストールまたは削除できるかどうかを判断する方法
- 環境からプラグインを削除する前に考慮すべきこと
- ユーザーが管理者が定義した範囲内で独自のワークスペースをカスタマイズする方法
