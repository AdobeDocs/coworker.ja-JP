# 同僚のプラグイン：彼らは何であるか、どのように動作するか、そしてそれらをインストールする方法

このビデオでは、プラグインを紹介し、新しい機能で[!DNL Coworker]を拡張する方法を説明します。 プラグインとは何か、含まれるコンポーネント、プラグインがスキルとMCP サーバーにどのように関連するか、およびワークスペースからプラグインをインストール、使用、削除する方法について説明します。

>[!VIDEO](https://video.tv.adobe.com/v/3503656/?learn=on&enablevpops)

## プラグインとは何ですか？

プラグインは、Adobe Coworkerの関連機能のインストール可能なパッケージです。 これは、特定のビジネス機能やユースケース向けに設計された、すぐに使用できるツールキットと考えてください。

プラグインには、次のようなものがあります。

- 特定のタスクを実行する専門的なスキル
- Coworkerを外部のAdobe ソリューションやサービスに接続するMCP サーバー
- デプロイメントと管理を簡素化するバンドル機能

## 主要な概念

このビデオでは、いくつかの重要なコンポーネント間の関係について説明します。

| コンポーネント | 目的 |
|-----------|---------|
| マーケットプレイス | 利用可能なプラグインが検出されるカタログ |
| プラグイン | インストール可能な機能パッケージ |
| スキル | 特定のタスクを実行する再利用可能な命令 |
| MCP サーバー | 外部ツールやサービスとのガバナンスされた接続 |

コネクテッドAdobeソリューションの例には、次のようなものがあります。

- Adobe Journey Optimizer
- Real-Time CDP
- Adobe Target
- Adobe Workfront

次の方法について説明します。

3. インストール済みのプラグインパッケージの確認
4. プラグインのソース情報と説明の表示
5. プラグインの詳細と機能の詳細

また、このビデオでは、設定、権限、有効な機能に基づいて、プラグインの可用性が組織によって異なる理由も説明しています。

## プラグイン機能の検討

プラグインには、次のような一般的な操作タスクを実行するのに役立つスキルの大規模なコレクションを含めることができます。

- 重複したオーディエンスの検索
- Experience Platform データフローの正常性の監視
- 顧客データの分析
- カスタマージャーニーの構築と最適化のサポート

## 新しいプラグインのインストール

このチュートリアルでは、次の方法を説明します。

1. 利用可能なマーケットプレイスを見る
2. プラグインを探す
3. プラグインの詳細を見る
4. プラグインのインストール
5. Coworker内で新機能を利用できるようにします

## Coworkerでのプラグインの使用

インストール後、このビデオでは、プラグインをチャット体験で使用する方法を説明します。

この例では、購入後にポイントを報酬として与える、ロイヤルティチャレンジを作成する様子を示しています。

実行時に、チームメンバーは次の透明性を提供します。

- 使用されているスキル
- データソースについて調べた
- 実行されたクエリ
- 成果の生成方法

## ガバナンスとセキュリティ

重要なポイントは、プラグインのインストールが組織のガバナンス管理をバイパスしないことです。

Coworkerは、次の項目を尊重し続けています。

- ユーザー権限
- アクセス制御
- 承認要件
- Adobeの組織ガバナンスポリシー

プラグインをインストールしても、ユーザーがまだ使用を許可されていない製品やアクションへのアクセス権は自動的に付与されません。

## プラグインの削除

最後に、インストールされたプラグインが不要になった場合に、そのプラグインを削除する方法を示します。

プラグインを削除すると、そのパッケージにバンドルされている機能も削除されます。

## 重要ポイント

プラグインを使用すると、関連するスキルと管理された接続をインストール可能なソリューションにパッケージ化することで、Coworkerを拡張可能にします。 マーケットプレイスは、ユーザーがプラグインを発見したり、特定のタスクを実行したりするのに役立ちます。また、MCP サーバーは、Coworkerを安全に管理された方法でAdobe Experience Cloudのアプリケーションやサービスに接続します。
