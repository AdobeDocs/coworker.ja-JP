# 同僚のカスタマイズの概要 {#overview}

カスタマイズにより、チームの働き方に合わせて同僚のエクスペリエンスを拡大し、パーソナライズできます。 繰り返し可能なワークフローを標準化するスキル、Coworkerを他のシステムに接続するための統合、関連する機能をインストール可能なパッケージにバンドルするプラグイン、会話をまたいで好みや作業スタイルを伝えるメモリを使用します。
