# プロンプトのベストプラクティス {#best-practices}

「同僚キャンペーンを最大限に活用するには」は、プロンプトの作成から始まります。 最良の結果を生み出すベストプラクティスについて説明します。プロンプトを構造化するCO-STAR フレームワーク、含めるべき事項と回避すべき事項、AIに関連性の高いターゲットに即したコンテンツを生成するために必要なコンテキストを提供するシナリオベースの例です。

>[!NOTE]
>
>現在、Coworker Campaignsでサポートされている統合にのみ接続できます。 オーディエンスの保存やジャーニーの構築を行う既存のAdobe Enterprise アプリケーションがある場合は、代わりに[CX Enterprise Coworker](/help/chat/use-cases/overview.md)を使用することをお勧めします。

## CO-STAR フレームワークの使用

最良の結果を得るには、CO-STAR フレームワークを使用してプロンプトを整理します。 この体系化されたアプローチにより、AIは貴社が必要としているものを正確に把握できます。

| コンポーネント | 意味 | これが重要な理由 |
|-|-|-|
| **C - コンテキスト** | キャンペーン、製品または状況に関する背景 | AIは全体像を把握するのに役立つ |
| **O - 目標** | 特定のマーケティング目標 | コンテンツが達成すべき目標を推進します |
| **S - スタイル** | コミュニケーション方法 | アプローチを設定します |
| **T - トーン** | 感情的なスタイルと声 | メッセージの雰囲気を形作ります |
| **A - オーディエンス** | ターゲティングするオーディエンス | メッセージが適切な対象者の共感を得られるようにします |
| **R - 要件** | 特定の制約または必須 | 境界と重要な要素を定義します |

### プロンプトでサポートされるコンテンツ

視覚や画像の変更には、**E メールエディター**&#x200B;または **Adobe Express** を使用します。 次のリクエストタイプがサポートされています。

- **キャンペーンの頻度と頻度を指定**:「毎週送信される電子メールキャンペーンを作成する…」

- **大きなリストから特定のオーディエンスをターゲット**:「All-attendees.csvから&#x200B;_Bark in the Park_ イベントの犬を持つ参加者のみを対象としたキャンペーンを作成する」

- **HTML ファイルをアップロード**:「添付されたHTML ファイルをベースとして使用して、電子メールキャンペーンを作成する」

- **会話の途中で変更する**:「このキャンペーンが終了するまでの日数を2日から3日に変更する」

### 品質チェックリスト

コンテンツを生成する前に、次の点を確認します。

✓ **目標を明確にする**: アクション、製品/サービス、値、およびコンテキストを明確に示します。

✓ **定義されたターゲットオーディエンス**: デモグラフィック、役割、またはセグメントを指定します。

✓ **デフォルトとして割り当てられた適切なブランド**：適切なブランドガイドラインが選択されています。

✓ **現実的な範囲**: レイアウトの変更、スタイル設定、構造的な編集のリクエストを避けます。

## 一般的なマーケティングプロンプトのアイデア

### コンテンツマーケティング

- 「初めて住宅を購入する人からよく寄せられる質問に答える20のブログのトピックを生成します。」
- 「LinkedInの投稿アイデアをブレインストーミングして、B2B サイバーセキュリティのスタートアップに役立てよう」
- 「新規顧客の教育に焦点を当てた3 ヶ月間のコンテンツカレンダーを作成する」
- 「ブログ、ビデオ、ニュースレター、ソーシャルメディアの投稿に再利用できるコンテンツのテーマを提案します。」

### メールマーケティング

- 「持続可能なファッションに関心のある新規購読者のために、ウェルカムメールのシーケンスを生成する」
- 「クリックベイトのように聞こえることなく、好奇心を生み出す件名をブレインストーミングしてください」。
- 「非アクティブな顧客に対してリエンゲージメントキャンペーンのアイデアを提案する」
- 「オンボーディングが完了したユーザー向けのライフサイクルメールのアイデアを作成する」
