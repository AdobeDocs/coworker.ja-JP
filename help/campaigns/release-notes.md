# Adobe CX Enterprise Coworker Campaigns リリースノート {#release-notes}

Coworker Campaignsのリリースは、継続的な配信モデルにもとづいて運用されるため、機能のデプロイメントに対してよりスケーラブルで段階的なアプローチが可能になります。

## 2026年9月 {#sep-2026}

**リリース日：2026年9月17日**

* Azure、GCP、またはカスタムドメインでホストされているDatabricks ワークスペースへの接続
* ワークフローが完全に設定されるまでキャンペーンを開始することはできません
* キャンペーンテンプレートが更新され、コンテンツが更新されました
* 連絡先リスト CSVのアップロード中に直接コネクタを選択する
* 体験版サインアップの長いリストをスクロールした後に発生する可能性があるクラッシュを修正しました
* 空白または重複ヘッダーを含むオーディエンス CSVをアップロードすると、ページがクラッシュする問題を修正しました
* 解決後に未入力で表示されるキャンペーンプロンプトのプレースホルダーテキストを修正しました
* カラーグラデーションが見つからないことによるスキルページのクラッシュを修正しました
* 修正されたチャットは、既に回答した後に同じ質問を繰り返し行き詰まる
* チャット応答では、選択した回答の前に迷路IDのプレフィックスが表示されなくなりました
* チャットでは、次の手順で簡単に返信できるようになりました。タップすると、作成ボックスに入力できます
* キャンペーンテンプレートが、個別のダイアログではなく、合理化されたページ内ビューで開くようになりました
* 拡張されたチャットの進行状況バーが、会話を表示せずに内部でスクロールするようになりました
* キャンペーン設定が、最新のボードの詳細をより正確に反映するようになりました
* アップグレードプランのダイアログで、より一貫性のあるルックアンドフィールが使用されるようになりました
* キャンペーン計画ヘッダーから冗長なステータスインジケーターを削除して、よりクリーンな外観を実現
* 迅速なメール編集は、多くの場合ではなく、単一のバージョン履歴エントリとして一緒に保存されるようになりました
* ドラフトの生成中にブランドキットのタイトルがブランクになることがある問題を修正しました
* Adobe Expressを使用して、画像ツールバーから直接画像を編集
* 手作業で更新することなく、基本的なエージェントオーディエンスデータがキャンペーンボード上で同期されるようになりました
* キャンペーンボードのブランドロゴは、スペースに合わせて切り抜かれます
* キャンペーンプランがキャンペーンボード上に移動する際の、よりスムーズな視覚的な引き継ぎ

**リリース日：2026年9月3日**

* チャットメッセージをコピーし、メッセージ自体から直接、親指を上げたり下げたりして、AIの応答を評価します
* キャンペーンの実行中、キャンペーンプランタスクリストがチャット入力の上に固定されるようになりました。これにより、スクロールしなくても進行状況を追跡できます
* Databricks SQL ウェアハウスをキャンペーンの新しいデータソースとして接続する
* 従来のチャットベースのメールエディターは廃止され、新しいメールアセットエディターに移行しました
* 体験版ユーザー管理では、Adobe ユーザーを除外できるようになりました。これにより、実際の体験版のサインアップを簡単に確認できます
* 類似キャンペーンの提案の読み込みに失敗する問題を修正しました
* チャットメッセージの間隔が狭まり、一貫性を維持できるようになりました

**リリース日：2026年9月1日**

* キャンペーンボードの起動ボタンが「レビューと起動」というラベル付けになり、わかりやすくなりました

* Salesforceには、コネクターリストに独自のロゴが追加されました
* 利用可能なコネクタは、近日公開されるコネクタよりも先にリストされるようになりました

* チャットは、一時的な進行状況メッセージ（「探索する…」など）を会話履歴に保持しなくなりました
* AIの画像またはテキスト候補の適用中に、ツールバーコントロールが適切にロックされるようになりました
* アセットエディターでの画像の置き換えが正しく機能しない問題を修正しました
