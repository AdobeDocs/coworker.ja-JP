# 画像からのジャーニーの作成

CX Enterprise Coworkerを利用して、マーケティング部門が作成したPowerPoint スライドなどのフローチャート画像を、すぐに編集できるジャーニーに変換する方法を解説します。 Coworkerが画像からプロンプトを抽出し、レビューと調整を行い、トリガーイベントを要求し、結果を元のデザインと一致するドラフトとして保存する方法が表示されます。
