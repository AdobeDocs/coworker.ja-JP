# Adobe Content Analytics導入の計画

CX Enterprise CoworkerのACA実装ガイドでは、Content Analyticsを既存のCustomer Journey Analytics（CJA）のデプロイメントに追加する場合でも、スタンドアロン設定から開始する場合でも、カスタマイズされたAdobe Content Analytics実装プランを作成する方法について説明します。

## 学習すること

- Coworkerがガイド付き検出プロセスを使用して、ライセンス、チャネル、SDK、行動データ、ID合成、プライバシー、レポート要件を取得する方法。
- 実装フェーズのシーケンス化、所有者の割り当て、依存関係の特定、クリティカルパスのタイムラインの見積もり方法について解説します。
- 既存のCJA導入とスタンドアロンのContent Analytics導入のプランの違い。
- 進捗状況の追跡、前提条件の修正、実装タスクのCSVおよびJiraへのエクスポート方法。

>[!VIDEO](https://video.tv.adobe.com/v/3508620/?learn=on&enablevpops)

## 既存のCJA デプロイメントへのContent Analyticsの追加

最初のチュートリアルは、すでにCJAをwebとモバイルで利用している企業から始まります。 Adobe TagsおよびWeb SDKはweb サイトをサポートし、Mobile SDKはアプリをサポートし、CJA接続、データビュー、データストリームは既に存在します。

回答にもとづいて、Coworker氏は、実装を成功させるために必要なあらゆるタスクと、実装チームの管理外の依存関係を考慮したプランを作成します。

## スタンドアロンのContent Analyticsの使用

2つ目のチュートリアルは、既存のCJA デプロイメントがないことから始まります。

Coworkerは、Adobeのアカウントチームで行動データの要件を確認し、web行動データのスキーマとデータセットを作成するための計画を作成します。 ガイド付きウィザードにより、CJA接続とデータビューが作成されます。

## 進捗状況の追跡と計画の書き出し

このビデオでは、手順を完了、再オープン、または延期とマークできる、インタラクティブな1 ページのトラッカーを示しています。 共同作業者は、実装の詳細が変更されたときにプランを更新し、そのファイルを再生成できます。

このガイドは、次のような他の書き出し形式をサポートしています。

- **CSV:** フェーズ、労力、所有者、依存関係、およびステータスを含む実装ステップ。
- **Jira:**&#x200B;優先度やストーリーポイントを含む、エピックとしてのフェーズとストーリーとしてのステップを含む、バックログ対応の構造。

## 重要なポイント

Adobe Adobe Customer Journey Analyticsの「ACA導入ガイド」では、導入要件を段階的かつ実行可能な計画に転換しています。 早い段階でセキュリティ、プライバシー、設定の依存関係を明らかにし、最初の環境に適応することで、Adobe Content Analyticsの導入を調整し、追跡できます。
