# CX Enterprise Coworkerで、アイデアからアクティベーション可能なオーディエンスを実現

Coworkerを使用して、平易な言語のリクエストをターゲットマーケティングオーディエンスに変える方法を説明します。 明確な質問に答えてオーディエンスを絞り込み、その後、Adobe Workfrontで直接作成させ、配信先をまたいで活用する、といった具合です。
